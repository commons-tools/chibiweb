# chibiwebで、自分のテーマをつくる人へ

chibiwebの見た目は、CSSファイル1枚で決まっています。
いま入っているテーマは、最初につくった人の好み（背景は白、文字は黒、見出しもゴシック、色は1色）が反映されたものです。ひとつの例にすぎません。
このページを読んで、自分のテーマをつくってください。

---

## 1. まず知っておくファイル

| ファイル | 場所 | 役割 |
|---|---|---|
| `DESIGN.md` | `docs/DESIGN.md` | デザインのルール。ページの型、使える部品、してはいけないこと。**テーマをつくる前に、必ず読む** |
| `style.css` | `public/assets/style.css` | 見た目のすべて。テーマをつくるときに直すのは、基本的にこのファイルだけ |
| 各ページのHTML | `public/*.html` | 中身と構造。テーマをつくるときは**直さない** |
| `site.json` | `public/site.json` | サイト名、ロゴ、メニュー、コピーライト。見た目ではなく中身 |

HTMLは、どのページも同じクラス名（`.page`、`.section`、`.prose`、`.info-list` など）で組んであります。
この名前を変えなければ、`style.css` を差し替えるだけで、すべてのページが新しいテーマに切り替わります。**クラス名は、HTMLとCSSのあいだの約束**です。

## 2. はじめる前に

`docs/DESIGN.md` の中でも、特にこの2つを読んでください。

- **【重要】見本の文章は、本物を想像して書く**：テーマを確かめるときも、「テキストテキスト」ではなく、本物らしい文章で見る
- **ページの型**：ホームと下層ページの並び順。テーマで見た目は変えても、この順番は変えない

## 3. `style.css` のどこを直せばいいか

`style.css` は、9つの章に分かれています。テーマをつくるときに直す場所は、上から順に、こうなります。

### ① まずは「1. デザインの変数」だけで（ファイルの先頭）

ここを変えるだけで、テーマの印象の大部分が決まります。**最初は、ここ以外をさわらずにつくってみてください。**

| 変数 | 決めるもの |
|---|---|
| `--color-text` | 文字の色 |
| `--color-text-sub` | 補足の文字（日付・注釈）の色 |
| `--color-bg` | 背景の色 |
| `--color-surface` | カード・表・地図の背景 |
| `--color-line` | 罫線の色 |
| `--color-accent` | リンク・ボタン・強調の色（1色） |
| `--color-accent-soft` | 緊急のお知らせ・注意書きの箱の背景 |
| `--font-body` | 本文の書体 |
| `--font-head` | 見出しの書体（いまは本文と同じゴシック。明朝にしたいならここ） |
| `--font-size-h1` 〜 `--font-size-small` | 文字の大きさ（見出し4段階＋本文＋小さい文字） |
| `--letter-spacing-head` / `--letter-spacing-body` | 字間（見出し・本文） |
| `--space` | 余白の単位。すべての余白はこの倍数 |
| `--content-width` | 本文の最大幅（いまは全角約40字） |
| `--radius` | 角丸の大きさ（カード、地図など） |
| `--header-height` | ヘッダーの高さ |

色を変えたら、文字と背景の色の差が十分あるか（WCAG AA、4.5:1以上）を確かめてください。

### ② レイアウトを変えたいときは「5. ページの骨組み」

- `.page`：本文の幅と、画面の左右の余白
- `.page-wide`：本文より広く使いたいところの幅
- `.page-head`：下層ページの見出し部分

ページの外枠を決めているのは、ここだけです。

### ③ ホームの見せ方を変えたいときは「7. トップページ」

- `.hero-image`：メイン写真の比率（いまはスマホで2:1、広い画面で3:1）
- `.hero`：お店のひとこと
- `.section` / `.section-title`：ホームの各ブロックの間隔と見出し

### ④ 部品の見た目を変えたいときは「6. 本文」と「8. お知らせ部品」

- 「6. 本文」：見出し、表、情報リスト、注意書きの箱、ボタン、地図など、`.prose` の中の部品
- 「8. お知らせ部品」：お知らせの一覧、緊急のお知らせの箱

### さわらなくていいところ

- 「2. 土台」「9. 補助」：どのテーマでも共通の基本。変えるときは理由があるときだけ
- 「3. ヘッダー」「4. フッター」：メニューの開け閉めの動きと関係しているので、色や余白以外を変えるときは、スマホでメニューが開けるかを必ず確かめる

## 4. 多段カラムについて

chibiwebは、最初から1段で組んでいます。スマホでは結局1段に積むしかなく、小さなお店のサイトでは、読む順番が1本に決まっているほうが迷わないからです。

サイドバーのような2段組みは、おすすめしません。広い画面で横に並べたいときは、ホームの「下層ページへの入口」のカードのように、部分的に並べるくらいがちょうどいいと思います。

## 5. してはいけないこと

- HTMLのクラス名を変える（テーマを入れ替えられなくなる）
- `style="…"` で、その場だけ見た目を変える
- 色を増やしすぎる（強調の色は1色から始める）
- スマホで確かめずに、PCの画面だけで決める

## 6. できたテーマを持ち寄る

- `style.css` を1枚のファイルとして、テーマの名前をつけて共有する（例：`theme-kinari.css`）
- ファイルの先頭のコメントに、テーマの名前、つくった人、どんなお店や団体に向いているかを書く
- 見本のパン屋さんのページで、スマホとPCのスクリーンショットを添える

テーマが2つ以上集まったら、`site.json` に1行書くだけで切り替えられるしくみをつくる予定です。

---

テーマづくりは、コードを書かない人でも参加できる、chibiwebのいちばん開かれた入口です。
